# Статья 296. Объединение жалоб и выделение жалоб
Таможенный орган, рассматривающий жалобу, вправе объединить для совместного рассмотрения несколько жалоб на взаимосвязанные решения, действия (бездействие) таможенного органа или выделить решения, действия (бездействие) таможенного органа из предмета обжалования для отдельного рассмотрения.
