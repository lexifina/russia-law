# Статья 3.
Минимальный размер оплаты труда применяется для регулирования оплаты труда и определения размеров пособий по временной нетрудоспособности, по беременности и родам, а также для иных целей обязательного социального страхования. Применение минимального размера оплаты труда для других целей не допускается. (В редакции федеральных законов от 20.04.2007 № 54-ФЗ; от 24.07.2009 № 213-ФЗ)
