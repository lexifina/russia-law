# Статья 14. Государственное регулирование норм и правил безопасного ведения работ по добыче (переработке) угля (горючих сланцев)
Правила безопасного ведения горных работ, обязательные для выполнения организациями по добыче (переработке) угля (горючих сланцев), определяются техническими регламентами, принимаемыми в соответствии с федеральным законодательством. (Статья в редакции Федерального закона от 22.08.2004 г. N 122-ФЗ)
