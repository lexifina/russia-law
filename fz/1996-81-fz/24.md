# Статья 24. Государственная поддержка мер по созданию новых рабочих мест для трудоустройства работников, высвобождаемых при ликвидации организаций по добыче (переработке) угля
1. В целях организации и поддержки предпринимательской, индивидуальной трудовой деятельности работников, высвобождаемых при ликвидации организаций по добыче (переработке) угля, Правительство Российской Федерации устанавливает меры по льготному кредитованию и страхованию их деятельности.
2. Высвобождаемые работники имеют приоритетное право на приобретение производственных помещений ликвидируемых организаций по добыче (переработке) угля или на их аренду для организации предпринимательской и индивидуальной трудовой деятельности.
