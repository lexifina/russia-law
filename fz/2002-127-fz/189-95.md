# Статья 189-95. Особенности удовлетворения требований кредиторов по субординированным кредитам
Требования кредиторов по субординированным кредитам (депозитам, займам, облигационным займам), а также по финансовым санкциям за неисполнение обязательств по субординированным кредитам (депозитам, займам, облигационным займам) удовлетворяются после удовлетворения требований всех иных кредиторов (статья 189-95 введена Федеральным законом от 22 декабря 2014 г. N 432-ФЗ - Собрание законодательства Российской Федерации, 2014, N 52, ст. 7543).
