# Статья 21². Группы саморегулируемых организаций арбитражных управляющих
1. Саморегулируемая организация арбитражных управляющих относится к одной из трех групп при соблюдении условий, предусмотренных настоящей статьей.
2. Минимальный размер сформированного компенсационного фонда саморегулируемой организации арбитражных управляющих составляет:
1) для первой группы - пятьдесят миллионов рублей;
2) для второй группы - сто миллионов рублей;
3) для третьей группы - четыреста миллионов рублей.
(Особенности применения пункта 2 - Федеральный закон от 26.07.2026 № 253-ФЗ)
3. Минимальный размер сформированного компенсационного фонда саморегулируемой организации арбитражных управляющих в расчете на одного члена саморегулируемой организации арбитражных управляющих должен составлять не менее одного миллиона рублей.
4. Минимальное количество завершенных процедур, применяемых в делах о банкротстве, за исключением процедур, применяемых в делах о банкротстве к отсутствующим должникам, в которых участвовали члены саморегулируемой организации арбитражных управляющих, в совокупности составляет:
1) для первой группы - двадцать;
2) для второй и третьей групп - сорок, за исключением процедур, применяемых в делах о банкротстве граждан.
5. Минимальное количество членов саморегулируемых организаций арбитражных управляющих составляет:
1) для первой группы - не менее десяти;
2) для второй и третьей групп - не менее двадцати.
6. Саморегулируемая организация первой группы вправе предлагать кандидатуру арбитражного управляющего только для должников первой группы.
Саморегулируемая организация второй группы вправе предлагать кандидатуру арбитражного управляющего только для должников первой и второй групп.
Саморегулируемая организация третьей группы вправе предлагать кандидатуру арбитражного управляющего для должников любой группы.
Если в единый государственный реестр саморегулируемых организаций арбитражных управляющих не включено ни одной саморегулируемой организации третьей группы, кандидатуру арбитражного управляющего для должников третьей группы вправе предлагать саморегулируемая организация второй группы.
Если в единый государственный реестр саморегулируемых организаций арбитражных управляющих не включено ни одной саморегулируемой организации второй и третьей групп, кандидатуру арбитражного управляющего для должников второй и третьей групп вправе предлагать саморегулируемая организация первой группы.
7. В уставе саморегулируемой организации указывается ее принадлежность к одной из групп саморегулируемых организаций. Саморегулируемая организация считается отнесенной к одной из групп саморегулируемых организаций с даты включения сведений о ее принадлежности к одной из групп саморегулируемых организаций в единый государственный реестр саморегулируемых организаций арбитражных управляющих. Решение общего собрания членов саморегулируемой организации по вопросу об отнесении саморегулируемой организации к одной из групп саморегулируемых организаций может быть принято только после формирования компенсационного фонда саморегулируемой организации в установленном размере.
8. Если вследствие выплат из компенсационного фонда саморегулируемой организации или иных причин размер компенсационного фонда саморегулируемой организации окажется меньше минимального размера, установленного для группы саморегулируемых организаций, к которой относится саморегулируемая организация, саморегулируемая организация обязана в течение трех месяцев пополнить свой компенсационный фонд до необходимого минимального размера, либо принять решение об отнесении саморегулируемой организации к группе, которой соответствует размер имеющегося у нее компенсационного фонда, либо принять решение о ликвидации саморегулируемой организации. Указанный срок может быть продлен не более чем на три месяца арбитражным судом по заявлению саморегулируемой организации при наличии объективных причин, свидетельствующих о возможности пополнения компенсационного фонда такой саморегулируемой организации в указанный срок. К участию в этом деле привлекаются кредиторы, требования которых подлежат погашению за счет компенсационного фонда саморегулируемой организации.
(Дополнение статьей - Федеральный закон от 26.07.2026 № 253-ФЗ)
