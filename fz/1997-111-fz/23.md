# Статья 23.
Общая сумма ассигнований по каждому разделу функциональной классификации расходов федерального бюджета на 1998 год с учетом принятых поправок не должна превышать сумму расходов по соответствующему разделу, утвержденную во втором чтении проекта федерального закона "О федеральном бюджете на 1998 год".
