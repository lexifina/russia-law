# Статья 11. Особенности использования лесов для размещения необходимых для проведения саммита объектов
1. Для размещения необходимых для проведения саммита объектов допускается использование лесов, за исключением лесов, расположенных на особо охраняемых природных территориях, и особо защитных участков лесов, в целях строительства, реконструкции, эксплуатации соответствующих объектов.
2. Для размещения необходимых для проведения саммита объектов в лесах, за исключением лесов, расположенных на особо охраняемых природных территориях, и особо защитных участков лесов, допускается осуществление рубок лесных насаждений без ограничений, предусмотренных лесным законодательством.
