# Статья 10. О внесении изменения в Федеральный закон "Об экологической экспертизе"
Пункт 4 статьи 14 Федерального закона от 23 ноября 1995 года N 174-ФЗ "Об экологической экспертизе" (Собрание законодательства Российской Федерации, 1995, N 48, ст. 4556; 2004, N 35, ст. 3607; 2006, N 1, ст. 10; 2008, N 20, ст. 2260; N 30, ст. 3618; 2009, N 1, ст. 17; N 19, ст. 2283; 2011, N 27, ст. 3880; N 30, ст. 4594; 2012, N 26, ст. 3446; 2013, N 23, ст. 2866; 2014, N 30, ст. 4220; 2015, N 1, ст. 72) дополнить словами ", если иное не предусмотрено федеральным законом".
