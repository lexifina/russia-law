# Статья 67. Оценка земельного участка при его ипотеке
1. Оценка земельного участка осуществляется в соответствии с законодательством, регулирующим оценочную деятельность в Российской Федерации.
2. Залоговая стоимость земельного участка, передаваемого в залог по договору об ипотеке, устанавливается по соглашению залогодателя с залогодержателем. Залоговая стоимость земельного участка из состава земель сельскохозяйственного назначения по соглашению залогодателя с залогодержателем может быть определена исходя из его кадастровой стоимости без проведения оценки рыночной стоимости такого земельного участка. (В редакции Федерального закона от 06.06.2019 № 138-ФЗ)
