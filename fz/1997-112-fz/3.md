# Статья 3.
Отнести Куранахскую группу месторождений золота, расположенную на территории Республики Саха (Якутия), к объектам, право пользования которыми может быть предоставлено на условиях раздела продукции. Пользователь недр на момент принятия настоящего Федерального закона - закрытое акционерное общество "Куранахская золотодобывающая компания".
