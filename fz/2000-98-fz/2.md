# Статья 2.
Установить, что коэффициенты деноминации для месяцев, входящих в период с 1 марта по 31 декабря 1991 года, имеют следующие численные значения:
для марта - 0,91;
для апреля - 0,52;
для мая - 0,51;
для июня - 0,50;
для июля - 0,50;
для августа - 0,51;
для сентября - 0,53;
для октября - 0,52;
для ноября - 0,49;
для декабря - 0,43.
