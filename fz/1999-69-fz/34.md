# Статья 34. Учетно-отчетное время для объектов систем газоснабжения
Для объектов систем газоснабжения независимо от местонахождения таких объектов решением Правительства Российской Федерации устанавливается единое учетно-отчетное время, которое определяет начало учетных суток, учетного месяца, учетного года для всех организаций, осуществляющих деятельность по добыче, транспортировке и поставкам газа.
