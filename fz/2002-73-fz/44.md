# Статья 44. Приспособление объекта культурного наследия для современного использования
Приспособление объекта культурного наследия для современного использования - научно-исследовательские, проектные и производственные работы, проводимые в целях создания условий для современного использования объекта культурного наследия, включая реставрацию представляющих собой историко-культурную ценность элементов объекта культурного наследия. (В редакции Федерального закона от 22.10.2014 № 315-ФЗ)
