# Статья 44. Приспособление объекта культурного наследия для современного использования
Приспособление объекта культурного наследия для современного использования - научно-исследовательские, проектные и производственные работы, проводимые в целях создания условий для современного использования объекта культурного наследия, включая реставрацию представляющих собой историко-культурную ценность элементов объекта культурного наследия (в ред. Федерального закона от 22 октября 2014 г. N 315-ФЗ - Собрание законодательства Российской Федерации, 2014, N 43, ст. 5799).
