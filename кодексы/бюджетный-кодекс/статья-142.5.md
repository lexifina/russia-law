# Статья 142.5. Иные межбюджетные трансферты из бюджетов городских, сельских поселений бюджетам муниципальных районов

В случаях и порядке, предусмотренных муниципальными правовыми актами представительного органа городского, сельского поселения, принимаемыми в соответствии с требованиями настоящего Кодекса, бюджетам муниципальных районов могут быть предоставлены иные межбюджетные трансферты из бюджетов городских, сельских поселений на осуществление части полномочий по решению вопросов местного значения в соответствии с заключенными соглашениями.
