# Статья 43⁹. Судебные составы Суда по интеллектуальным правам
1. В Суде по интеллектуальным правам председателем Суда по интеллектуальным правам образуются судебные составы из числа судей Суда по интеллектуальным правам с учетом специализации судей.
2. Судебный состав возглавляет председатель, утверждаемый президиумом Суда по интеллектуальным правам сроком на три года. Один и тот же судья может быть утвержден на должность председателя судебного состава неоднократно.
(Статья введена - Федеральный конституционный закон от 06.12.2011 № 4-ФКЗ)
