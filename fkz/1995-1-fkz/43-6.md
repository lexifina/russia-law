# Статья 43⁶. Полномочия президиума Суда по интеллектуальным правам
1. Президиум Суда по интеллектуальным правам осуществляет в кассационном порядке проверку законности вступивших в законную силу судебных актов Суда по интеллектуальным правам, принятых им по первой инстанции.
2. Президиум Суда по интеллектуальным правам:
1) утверждает по представлению председателя Суда по интеллектуальным правам председателей судебных составов Суда по интеллектуальным правам;
2) рассматривает другие вопросы организации работы Суда по интеллектуальным правам;
3) рассматривает вопросы судебной практики.
(Статья введена - Федеральный конституционный закон от 06.12.2011 № 4-ФКЗ)
