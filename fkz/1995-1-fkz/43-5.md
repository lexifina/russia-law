# Статья 43-5. Президиум Суда по интеллектуальным правам
1. Президиум Суда по интеллектуальным правам действует в составе председателя Суда по интеллектуальным правам, его заместителей, председателей судебных составов и судей, входящих в состав президиума Суда по интеллектуальным правам в соответствии с пунктом 2 настоящей статьи.
2. Судьи Суда по интеллектуальным правам, входящие в состав президиума Суда по интеллектуальным правам, утверждаются Пленумом Высшего Арбитражного Суда Российской Федерации по представлению председателя Суда по интеллектуальным правам сроком на два года. Один и тот же судья может быть введен в состав президиума Суда по интеллектуальным правам неоднократно.
(Статья дополнена - Федеральный конституционный закон от 06.12.2011 г. N 4-ФКЗ)
