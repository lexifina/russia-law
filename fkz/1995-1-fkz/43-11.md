# Статья 43¹¹. Заместители председателя Суда по интеллектуальным правам
1. Заместители председателя Суда по интеллектуальным правам являются судьями и осуществляют процессуальные полномочия, установленные Арбитражным процессуальным кодексом Российской Федерации.
2. Заместители председателя Суда по интеллектуальным правам в соответствии с распределением обязанностей организуют деятельность структурных подразделений аппарата суда, а в случае образования судебных коллегий возглавляют судебные коллегии.
3. В случае отсутствия председателя Суда по интеллектуальным правам его полномочия по поручению председателя осуществляет один из заместителей председателя.
(Дополнение статьей - Федеральный конституционный закон от 06.12.2011 № 4-ФКЗ)
