# Статья 262. Учет исполнения федерального бюджета
Все доходы федерального бюджета, поступления из источников финансирования дефицита федерального бюджета, расходы федерального бюджета, дефицит федерального бюджета, профицит федерального бюджета, а также все операции со средствами федерального бюджета отражаются Федеральным казначейством в соответствующих регистрах учета.
Единую методологию учета исполнения федерального бюджета на основе плана счетов устанавливает, организует и осуществляет Федеральное казначейство.
