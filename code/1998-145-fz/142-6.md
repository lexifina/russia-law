# Статья 142⁶. Иные межбюджетные трансферты бюджетам внутригородских районов из бюджетов городских округов с внутригородским делением
В случаях и порядке, предусмотренных муниципальными правовыми актами представительного органа городского округа с внутригородским делением, принимаемыми в соответствии с требованиями настоящего Кодекса и соответствующими этим требованиям законами субъекта Российской Федерации, бюджетам внутригородских районов могут быть предоставлены иные межбюджетные трансферты из бюджета городского округа с внутригородским делением. (Статья введена - Федеральный закон от 29.11.2014 № 383-ФЗ)
