# Статья 242²¹. Обеспечение наличными денежными средствами и денежными средствами, предназначенными для осуществления расчетов по операциям, совершаемым с использованием платежных карт
Обеспечение наличными денежными средствами и денежными средствами, предназначенными для осуществления расчетов по операциям, совершаемым с использованием платежных карт, участников системы казначейских платежей осуществляется Федеральным казначейством с открытием в соответствии с положениями статей 155 и 156 настоящего Кодекса банковского счета, предназначенного для выдачи и внесения наличных денежных средств и осуществления расчетов по отдельным операциям. (Статья введена - Федеральный закон от 27.12.2019 № 479-ФЗ)
