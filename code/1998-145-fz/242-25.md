# Статья 242²⁵. Средства, подлежащие казначейскому сопровождению, источником финансового обеспечения которых являются средства, предоставляемые из федерального бюджета
Казначейскому сопровождению подлежат определенные федеральным законом о федеральном бюджете средства, получаемые на основании государственных контрактов, договоров (соглашений), контрактов (договоров).
(Статья введена - Федеральный закон от 01.07.2021 № 244-ФЗ)
