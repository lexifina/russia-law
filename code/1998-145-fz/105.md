# Статья 105. Реструктуризация долга
1. Под реструктуризацией долга в целях настоящего Кодекса понимается погашение долговых обязательств с одновременным осуществлением заимствований (принятием на себя других долговых обязательств) в объемах погашаемых долговых обязательств с установлением иных условий обслуживания долговых обязательств и сроков их погашения.
2. Реструктуризация долга может быть осуществлена с частичным списанием (сокращением) суммы основного долга.
3. Сумма погашения основного долга за счет реструктуризации долга не включается в объем обслуживания долгового обязательства в текущем году.
