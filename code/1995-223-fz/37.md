# Статья 37. Признание имущества каждого из супругов их совместной собственностью
Имущество каждого из супругов может быть признано судом их совместной собственностью, если будет установлено, что в период брака за счет общего имущества супругов или имущества каждого из супругов либо труда одного из супругов были произведены вложения, значительно увеличивающие стоимость этого имущества (капитальный ремонт, реконструкция, переоборудование и другие). (В редакции Федерального закона от 30.12.2015 г. N 457-ФЗ)
