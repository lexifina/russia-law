# Статья 346-52. Налоговая декларация
Налоговая декларация по налогу, уплачиваемому в связи с применением патентной системы налогообложения, в налоговые органы не представляется (статья 346-52 введена Федеральным законом от 25 июня 2012 г. N 94-ФЗ - Собрание законодательства Российской Федерации, 2012, N 26, ст. 3447).
