# Статья 379. Налоговый период. Отчетный период
1. Налоговым периодом признается календарный год.
2. Отчетными периодами признаются первый квартал, полугодие и девять месяцев календарного года, если иное не предусмотрено настоящим пунктом. (В редакции Федерального закона от 28.11.2015 № 327-ФЗ)
Отчетными периодами для налогоплательщиков, исчисляющих налог исходя из кадастровой стоимости, признаются первый квартал, второй квартал и третий квартал календарного года. (Дополнение абзацем - Федеральный закон от 28.11.2015 № 327-ФЗ)
3. Законодательный (представительный) орган субъекта Российской Федерации при установлении налога вправе не устанавливать отчетные периоды.
