# Статья 333⁴. Порядок исчисления сборов
1. Сумма сбора за пользование объектами животного мира определяется в отношении каждого объекта животного мира, указанного в пунктах 1 - 3 статьи 333³ настоящего Кодекса, как произведение соответствующего количества объектов животного мира и ставки сбора, установленной для соответствующего объекта животного мира.
2. Сумма сбора за пользование объектами водных биологических ресурсов определяется в отношении каждого объекта водных биологических ресурсов, указанного в пунктах 4 - 7 статьи 333³ настоящего Кодекса, как произведение соответствующего количества объектов водных биологических ресурсов и ставки сбора, установленной для соответствующего объекта водных биологических ресурсов на дату начала срока действия разрешения. (В редакции Федерального закона от 29.11.2007 № 285-ФЗ)
