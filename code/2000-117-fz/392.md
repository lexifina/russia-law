# Статья 392. Особенности определения налоговой базы в отношении земельных участков, находящихся в общей собственности, пожизненном наследуемом владении
(Наименование в редакции Федерального закона от 28.11.2025 № 425-ФЗ)
1. Налоговая база в отношении земельных участков, находящихся в общей долевой собственности, определяется для каждого из налогоплательщиков, являющихся собственниками данного земельного участка, пропорционально его доле в общей долевой собственности.
2. Налоговая база в отношении земельных участков, находящихся в общей совместной собственности, определяется для каждого из налогоплательщиков, являющихся собственниками данного земельного участка, в равных долях.
3. (Пункт утратил силу - Федеральный закон от 29.09.2019 № 325-ФЗ)
4. Налоговая база в отношении земельных участков, принадлежащих нескольким налогоплательщикам на праве пожизненного наследуемого владения, определяется для каждого из таких налогоплательщиков в равных долях. (Дополнение пунктом - Федеральный закон от 28.11.2025 № 425-ФЗ)
