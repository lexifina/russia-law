# Статья 346⁴⁷. Объект налогообложения
Объектом налогообложения признается потенциально возможный к получению годовой доход индивидуального предпринимателя по соответствующему виду предпринимательской деятельности, установленный законом субъекта Российской Федерации. (Статья введена - Федеральный закон от 25.06.2012 № 94-ФЗ)
