# Статья 367. Налоговая база
По каждому из объектов налогообложения, указанных в статье 366 настоящего Кодекса, налоговая база определяется отдельно как общее количество соответствующих объектов налогообложения (статья 367 введена Федеральным законом от 27 декабря 2002 г. N 182-ФЗ - Собрание законодательства Российской Федерации, 2002, N 52, ст. 5138).
