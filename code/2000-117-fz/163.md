# Статья 163. Налоговый период
Налоговый период (в том числе для налогоплательщиков, исполняющих обязанности налоговых агентов, далее - налоговые агенты) устанавливается как квартал (в ред. Федерального закона от 27 июля 2006 г. N 137-ФЗ - Собрание законодательства Российской Федерации, 2006, N 31, ст. 3436).
