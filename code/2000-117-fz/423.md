# Статья 423. Расчетный период. Отчетный период
1. Расчетным периодом признается календарный год.
2. Отчетными периодами признаются первый квартал, полугодие, девять месяцев календарного года.
(Статья 423 введена Федеральным законом от 3 июля 2016 г. N 243-ФЗ - Собрание законодательства Российской Федерации, 2016, N 27, ст. 4176)
