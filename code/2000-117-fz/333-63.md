# Статья 333⁶³. Порядок и сроки уплаты налога
Налог, подлежащий уплате по итогам налогового периода, уплачивается налогоплательщиком в бюджет по месту регистрации объектов налогообложения (в отношении объектов налогообложения, указанных в пункте 1 статьи 333⁵⁸ настоящего Кодекса), по месту нахождения организации (в отношении объекта налогообложения, указанного в пункте 2 статьи 333⁵⁸ настоящего Кодекса) не позднее 28-го числа месяца, следующего за истекшим налоговым периодом.
