# Статья 62. Наследование права аренды земельного участка граждан, ведущих крестьянское (фермерское) хозяйство
Наследование права аренды земельного участка граждан, ведущих крестьянское (фермерское) хозяйство, происходит в порядке, предусмотренном частями первой, второй и третьей статьи 61 настоящего Кодекса.
При перезаключении договора аренды на часть земельного участка наследнику возмещаются затраты, связанные с повышением плодородия почв той части земельного участка, на которую не распространяется право наследования аренды.
