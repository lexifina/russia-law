# Статья 60. Порядок предоставления земельных участков для ведения крестьянского (фермерского) хозяйства из земель запаса и земель государственного лесного фонда
Гражданам, не являющимся членами колхозов, работниками сельскохозяйственных предприятий, земельные участки для организации крестьянского (фермерского) хозяйства предоставляются из земель запаса, либо из специального фонда земель, права на которые прекращаются в соответствии с пунктами 1, 2, 3, 4, 6, 8, 9 статьи 39 и частью третьей статьи 40 настоящего Кодекса, а также земель лесохозяйственных предприятий, не покрытых лесом и кустарником и пригодных для использования в сельскохозяйственном производстве.
