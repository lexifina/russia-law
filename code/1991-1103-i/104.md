# Статья 104. Охрана ценных сельскохозяйственных угодий
В целях охраны ценных сельскохозяйственных угодий (с учетом кадастровой оценки) краевые, областные, автономных областей, автономных округов Советы народных депутатов устанавливают границы территорий, в пределах которых запрещается изъятие земель для несельскохозяйственных нужд.
В республиках, входящих в состав РСФСР, границы указанных территорий устанавливаются законодательством этих республик.
