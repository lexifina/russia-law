# Статья 77. Земли сельскохозяйственного использования и другие угодья
К землям сельскохозяйственного использования в городах, поселках, сельских населенных пунктах относится пашня, сады, виноградники, огороды, сенокосы, пастбища. К другим угодьям относятся кустарники, торфяники, овраги, карьеры и другие.
Указанные земли используются колхозами, совхозами, другими предприятиями, учреждениями, организациями и гражданами для ведения сельского хозяйства, а также для других нужд городского хозяйства.
