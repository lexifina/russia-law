# Статья 129². Нарушение порядка регистрации объектов игорного бизнеса
1. Нарушение установленного настоящим Кодексом порядка регистрации в налоговом органе объекта налогообложения налогом на игорный бизнес либо порядка регистрации изменений количества объектов налогообложения- (В редакции Федерального закона от 23.07.2013 № 248-ФЗ)
влечет взыскание штрафа в трехкратном размере ставки налога на игорный бизнес, установленной для соответствующего объекта налогообложения.
2. Те же деяния, совершенные более одного раза, -
влекут взыскание штрафа в шестикратном размере ставки налога на игорный бизнес, установленной для соответствующего объекта налогообложения.
(Статья введена - Федеральный закон от 27.07.2006 № 137-ФЗ)
