# Статья 129¹⁶. Нарушение оператором майнинговой инфраструктуры обязанности по сообщению сведений, связанных с осуществлением майнинга цифровой валюты лицом, которому данный оператор оказывает услуги по предоставлению майнинговой инфраструктуры
Несообщение в установленный срок оператором майнинговой инфраструктуры в налоговый орган сведений, предусмотренных статьей 86⁵ настоящего Кодекса,
влечет взыскание штрафа в размере 40 тысяч рублей.
(Дополнение статьей - Федеральный закон от 29.11.2024 № 418-ФЗ)
