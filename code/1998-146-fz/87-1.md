# Статья 87-1. Налоговые проверки, проводимые таможенными органами
Таможенные органы проводят камеральные и выездные проверки в отношении налогов, подлежащих уплате в связи с перемещением товаров через таможенную границу Российской Федерации, в соответствии с правилами, предусмотренными статьями 87-89 настоящего Кодекса. (Статья дополнена - Федеральный закон от 09.07.99 г. N 154-ФЗ)
