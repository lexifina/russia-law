# Статья 341⁴. Расследование несчастного случая, происшедшего с работником, направленным временно для работы по договору о предоставлении труда работников (персонала) и участвовавшим в производственной деятельности принимающей стороны
Несчастный случай, происшедший с работником, направленным временно для работы у принимающей стороны по договору о предоставлении труда работников (персонала) и участвовавшим в производственной деятельности принимающей стороны, расследуется комиссией, образованной принимающей стороной. В состав комиссии входит представитель работодателя, направившего этого работника. Неприбытие или несвоевременное прибытие указанного представителя не является основанием для изменения сроков расследования (часть пятая статьи 229 настоящего Кодекса). (Статья введена - Федеральный закон от 05.05.2014 № 116-ФЗ)
