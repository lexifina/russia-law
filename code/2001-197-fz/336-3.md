# Статья 336³. Дополнительные основания прекращения трудового договора с руководителем, заместителем руководителя научной организации
Помимо оснований, предусмотренных настоящим Кодексом и иными федеральными законами, основанием прекращения трудового договора с руководителем, заместителем руководителя государственной или муниципальной научной организации является достижение предельного возраста для замещения соответствующей должности в соответствии со статьей 336² настоящего Кодекса.
