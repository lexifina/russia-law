# Статья 376. Гарантии права на труд работникам, являвшимся членами выборного профсоюзного органа
Расторжение трудового договора по инициативе работодателя по пункту 2, подпункту "б" пункта 3 и пункту 5 статьи 81 настоящего Кодекса с руководителем выборного профсоюзного органа данной организации и его заместителями в течение двух лет после окончания срока их полномочий допускается только с соблюдением порядка, установленного статьей 374 настоящего Кодекса.
