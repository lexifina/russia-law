# Статья 418. Ведение документации при разрешении коллективного трудового спора
Действия сторон коллективного трудового спора, соглашения и решения, принимаемые в связи с разрешением этого спора, оформляются протоколами представителями сторон коллективного трудового спора, примирительными органами, органом, возглавляющим забастовку. (В редакции Федерального закона от 30.06.2006 г. N 90-ФЗ)
