# Статья 32. Обязанности работодателя по созданию условий, обеспечивающих деятельность представителей работников
Работодатель обязан создавать условия, обеспечивающие деятельность представителей работников, в соответствии с трудовым законодательством, коллективным договором, соглашениями. (В редакции Федерального закона от 30.06.2006 № 90-ФЗ)
