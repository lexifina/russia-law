# Статья 351⁴. Дополнительные основания прекращения трудового договора с помощником, работником нотариуса
(Наименование в редакции Федерального закона от 29.12.2015 № 391-ФЗ)
Наряду с основаниями, предусмотренными настоящим Кодексом, дополнительные основания прекращения трудового договора с помощником, работником нотариуса могут быть установлены законодательством о нотариате. (В редакции Федерального закона от 29.12.2015 № 391-ФЗ)
(Статья введена - Федеральный закон от 29.12.2014 № 457-ФЗ)
