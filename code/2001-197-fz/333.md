# Статья 333. Продолжительность рабочего времени педагогических работников
Для педагогических работников образовательных учреждений устанавливается сокращенная продолжительность рабочего времени не более 36 часов в неделю.
Учебная нагрузка педагогического работника образовательного учреждения, оговариваемая в трудовом договоре, может ограничиваться верхним пределом в случаях, предусмотренных типовым положением об образовательном учреждении соответствующих типа и вида, утверждаемым Правительством Российской Федерации.
В зависимости от должности и (или) специальности педагогическим работникам образовательных учреждений с учетом особенностей их труда продолжительность рабочего времени (нормы часов педагогической работы за ставку заработной платы) определяется Правительством Российской Федерации. Педагогическим работникам разрешается работа по совместительству, в том числе по аналогичной должности, специальности.
