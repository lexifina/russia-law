# Статья 341³. Особенности регулирования труда работников, направляемых временно работодателем, не являющимся частным агентством занятости, к другим юридическим лицам по договору о предоставлении труда работников (персонала)
Особенности регулирования труда работников, направляемых временно к другим юридическим лицам по договору о предоставлении труда работников (персонала), работодателем, не являющимся частным агентством занятости, устанавливаются федеральным законом. (Статья введена - Федеральный закон от 05.05.2014 № 116-ФЗ)
