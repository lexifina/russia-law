# Статья 183. Гарантии работнику при временной нетрудоспособности
При временной нетрудоспособности работодатель выплачивает работнику пособие по временной нетрудоспособности в соответствии с федеральными законами. (В редакции Федерального закона от 30.06.2006 № 90-ФЗ)
Размеры пособий по временной нетрудоспособности и условия их выплаты устанавливаются федеральными законами. (В редакции Федерального закона от 30.06.2006 № 90-ФЗ)
