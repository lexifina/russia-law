# Статья 262¹. Очередность предоставления ежегодных оплачиваемых отпусков лицам, воспитывающим детей-инвалидов
Одному из родителей (опекуну, попечителю, приемному родителю), воспитывающему ребенка-инвалида в возрасте до восемнадцати лет, ежегодный оплачиваемый отпуск предоставляется по его желанию в удобное для него время. (Статья введена - Федеральный закон от 13.07.2015 № 242-ФЗ)
