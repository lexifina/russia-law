# Статья 408. Соглашение в ходе разрешения коллективного трудового спора
Соглашение, достигнутое сторонами коллективного трудового спора в ходе разрешения этого спора, оформляется в письменной форме и имеет для сторон коллективного трудового спора обязательную силу. Контроль за его выполнением осуществляется сторонами коллективного трудового спора. (В редакции Федерального закона от 30.06.2006 г. N 90-ФЗ)
