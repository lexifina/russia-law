# Статья 312⁵. Дополнительные гарантии по оплате труда дистанционного работника
Выполнение работником трудовой функции дистанционно не может являться основанием для снижения ему заработной платы. (Статья введена - Федеральный закон от 05.04.2013 № 60-ФЗ) (В редакции Федерального закона от 08.12.2020 № 407-ФЗ)
