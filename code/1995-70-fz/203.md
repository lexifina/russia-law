# Статья 203. Восстановление пропущенного срока для предъявления исполнительного листа к исполнению
1. При пропуске срока для предъявления исполнительного листа к исполнению по причинам, признанным арбитражным судом уважительными, пропущенный срок может быть восстановлен.
2. Заявление о восстановлении пропущенного срока подается в арбитражный суд, принявший судебный акт. Заявление рассматривается в заседании арбитражного суда с извещением взыскателя и должника заказным письмом с уведомлением о вручении, однако их неявка не является препятствием к рассмотрению заявлении.
3. По результатам рассмотрения заявления выносится определение, которое направляется взыскателю и должнику.
4. Определение может быть обжаловано.
