# Статья 133. Решение арбитражного суда об установлении факта, имеющего юридическое значение
При удовлетворении судом заявления об установлении факта, имеющего юридическое значение, в решении должен быть изложен установленный факт.
Решение арбитражного суда об установлении факта, имеющего юридическое значение, служит основанием для регистрации такого факта или для оформления прав, которые возникают в связи с установленным фактом, соответствующими органами.
