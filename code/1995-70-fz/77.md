# Статья 77. Замена одного вида обеспечения иска другим
1. Допускается замена одного вида обеспечения иска другим.
2. Вопрос о замене одного вида обеспечения иска другим разрешается в порядке, предусмотренном в статье 75 настоящего Кодекса.
3. При обеспечении иска о взыскании денежных средств ответчик вправе вместо принятия установленных мер по обеспечению иска внести на депозитный счет арбитражного суда истребуемую истцом сумму.
