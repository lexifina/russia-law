# Статья 144. Рассмотрение дел об установлении фактов, имеющих юридическое значение
1. Заявления об установлении фактов, имеющих юридическое значение, оформляются в соответствии с правилами, предусмотренными в статье 102 настоящего Кодекса.
2. Дела об установлении фактов, имеющих юридическое значение, рассматриваются арбитражным судом в порядке, предусмотренном настоящим Кодексом.
