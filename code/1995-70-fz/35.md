# Статья 35. Участие в деле нескольких истцов или ответчиков
1. Иск может быть предъявлен совместно несколькими истцами или к нескольким ответчикам. Каждый из истцов или ответчиков выступает в процессе самостоятельно. Соучастники могут поручить ведение дела одному из соучастников.
2. При необходимости привлечения другого ответчика арбитражный суд до принятия решения с согласия истца привлекает этого ответчика.
