# Статья 27. Подсудность дел об установлении фактов, имеющих юридическое значение
Дела об установлении фактов, имеющих юридическое значение, рассматриваются по месту нахождения заявителя, за исключением дел об установлении факта владения зданием, сооружением, земельным участком, которые рассматриваются по месту нахождения здания, сооружения, земельного участка.
