# Статья 196. Определение арбитражного суда о пересмотре дела
1. Арбитражный суд, рассмотрев заявление о пересмотре по вновь открывшимся обстоятельствам вступившего в законную силу судебного акта, удовлетворяет заявление и отменяет судебный акт либо отказывает в пересмотре.
2. Определение арбитражного суда об отказе в удовлетворении заявления о пересмотре по вновь открывшимся обстоятельствам судебного акта может быть обжаловано.
3. В случае отмены судебного акта дело рассматривается арбитражным судом по правилам, установленным настоящим Кодексом.
