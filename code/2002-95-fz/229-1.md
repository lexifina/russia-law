# Статья 229¹. Судебный приказ
1. Судебный приказ - судебный акт, вынесенный судьей единолично на основании заявления о взыскании денежных сумм по требованиям взыскателя, предусмотренным статьей 229² настоящего Кодекса.
2. Судебный приказ является одновременно исполнительным документом и приводится в исполнение в порядке, установленном для исполнения судебных решений.
