# Статья 256². Компетенция арбитражных судов по делам с участием иностранного государства
Компетенция судов Российской Федерации по рассмотрению дел с участием иностранного государства определяется по правилам, установленным главой 4 настоящего Кодекса. (Статья введена - Федеральный закон от 29.12.2015 № 393-ФЗ) (В редакции Федерального закона от 28.11.2018 № 451-ФЗ)
