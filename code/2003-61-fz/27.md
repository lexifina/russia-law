# Статья 27. Специальная таможенная статистика
1. В целях обеспечения решения возложенных на таможенные органы задач указанными органами ведется специальная таможенная статистика в порядке, который устанавливается федеральным органом исполнительной власти, уполномоченным в области таможенного дела. (В редакции федеральных законов от 29.06.2004 г. N 58-ФЗ; от 26.06.2008 г. N 103-ФЗ)
2. Данные специальной таможенной статистики используются таможенными органами исключительно для таможенных целей.
