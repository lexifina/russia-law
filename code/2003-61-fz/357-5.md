# Статья 357-5. Плательщики таможенных сборов
Плательщиками таможенных сборов являются декларанты и иные лица, на которых настоящим Кодексом возложена обязанность уплачивать таможенные сборы. (Статья дополнена - Федеральный закон от 11.11.2004 г. N 139-ФЗ; в редакции Федерального закона от 09.04.2009 г. N 58-ФЗ)
