# Статья 146. Специалист по таможенному оформлению
1. Специалистом по таможенному оформлению является физическое лицо, отвечающее квалификационным требованиям, установленным федеральным органом исполнительной власти, уполномоченным в области таможенного дела, и имеющее квалификационный аттестат специалиста по таможенному оформлению. (В редакции федеральных законов от 29.06.2004 г. N 58-ФЗ; от 26.06.2008 г. N 103-ФЗ)
2. Специалист по таможенному оформлению осуществляет свою деятельность в качестве работника таможенного брокера (представителя).
