# Статья 153³. Виды примирительных процедур
Споры могут быть урегулированы путем проведения переговоров, посредничества, в том числе медиации, судебного примирения, или использования других примирительных процедур, если это не противоречит федеральному закону. (Статья введена - Федеральный закон от 26.07.2019 № 197-ФЗ)
