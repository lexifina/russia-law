# Статья 375⁷. Срок рассмотрения кассационных жалобы, представления
В верховном суде республики, краевом, областном суде, суде города федерального значения, суде автономной области, суде автономного округа кассационные жалоба, представление рассматриваются в срок, не превышающий двух месяцев с даты поступления кассационных жалобы, представления с делом, и в срок, не превышающий трех месяцев, если кассационные жалоба, представление с делом переданы для рассмотрения в судебном заседании президиума верховного суда республики, краевого, областного суда, суда города федерального значения, суда автономной области, суда автономного округа.
