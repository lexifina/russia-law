# Статья 394. Подача заявления, представления о пересмотре судебных постановлений по вновь открывшимся или новым обстоятельствам
Заявление, представление о пересмотре судебных постановлений по вновь открывшимся или новым обстоятельствам подаются сторонами, прокурором, другими лицами, участвующими в деле, в суд, принявший эти постановления. Указанные заявление, представление могут быть поданы в течение трех месяцев со дня установления оснований для пересмотра. (Статья в редакции Федерального закона от 09.12.2010 г. N 353-ФЗ)
