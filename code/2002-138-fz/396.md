# Статья 396. Рассмотрение заявления о пересмотре по вновь открывшимся обстоятельствам решения, определения суда
Суд рассматривает заявление о пересмотре по вновь открывшимся обстоятельствам решения, определения суда в судебном заседании. Стороны, прокурор, другие лица, участвующие в деле, извещаются о времени и месте судебного заседания, однако их неявка не является препятствием к рассмотрению заявления.
