# Статья 5. Осуществление правосудия только судами
Правосудие по гражданским делам, относящихся к компетенции судов общей юрисдикции, осуществляется только этими судами по правилам, установленным законодательством о гражданском судопроизводстве. (В редакции Федерального закона от 28.11.2018 № 451-ФЗ)
