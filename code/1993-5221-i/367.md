# Статья 367. Предъявление в суд исков
Должностное лицо таможенного органа Российской Федерации, рассматривающее дело о нарушении таможенных правил, при выявлении в ходе производства по делу или его рассмотрения данных о противоправном характере сделок вправе предъявлять в суд иски о признании таких сделок недействительными.
