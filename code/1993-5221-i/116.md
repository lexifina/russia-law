# Статья 116. Таможенные сборы за таможенное сопровождение товаров
За таможенное сопровождение товаров взимаются таможенные сборы в размерах, определяемых федеральным органом исполнительной власти, осуществляющим нормативно-правовое регулирование в области таможенного дела, по согласованию с федеральным органом исполнительной власти, осуществляющим нормативно-правовое регулирование в области финансов. (В редакции Федерального закона от 29.06.2004 г. N 58-ФЗ)
