# Статья 239². Соединение уголовных дел
Суд при наличии оснований, предусмотренных настоящим Кодексом и возникших после поступления уголовного дела в суд, вправе по ходатайству стороны принять решение о соединении уголовных дел в одно производство. (Статья введена - Федеральный закон от 03.07.2016 № 327-ФЗ)
