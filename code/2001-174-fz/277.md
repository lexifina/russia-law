# Статья 277. Допрос потерпевшего
1. Потерпевший допрашивается в порядке, установленном частями второй - шестой статьи 278 и статьей 278-1 настоящего Кодекса (в ред. Федерального закона от 20 марта 2011 г. N 39-ФЗ - Собрание законодательства Российской Федерации, 2011, N 13, ст. 1686).
2. Потерпевший с разрешения председательствующего может давать показания в любой момент судебного следствия.
