# Статья 67. Отвод следователя или дознавателя
1. Решение об отводе следователя принимает руководитель следственного органа, а решение об отводе дознавателя принимает прокурор. (В редакции Федерального закона от 05.06.2007 г. N 87-ФЗ)
2. Предыдущее участие следователя, дознавателя в производстве предварительного расследования по данному уголовному делу не является основанием для его отвода.
