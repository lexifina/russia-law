# Статья 317. Пределы обжалования приговора
Приговор, постановленный в соответствии со статьей 316 настоящего Кодекса, не может быть обжалован в апелляционном порядке по основанию, предусмотренному пунктом 1 статьи 389¹⁵ настоящего Кодекса (в ред. Федерального закона от 29.12.2010 № 433-ФЗ).
ГЛАВА 40¹. ОСОБЫЙ ПОРЯДОК ПРИНЯТИЯ СУДЕБНОГО РЕШЕНИЯ ПРИ ЗАКЛЮЧЕНИИ ДОСУДЕБНОГО СОГЛАШЕНИЯ О СОТРУДНИЧЕСТВЕ
(глава введена Федеральным законом от 29.06.2009 № 141-ФЗ)
