# Статья 317. Пределы обжалования приговора
Приговор, постановленный в соответствии со статьей 316 настоящего Кодекса, не может быть обжалован в апелляционном порядке по основанию, предусмотренному пунктом 1 статьи 389-15 настоящего Кодекса (в ред. Федерального закона от 29 декабря 2010 г. N 433-ФЗ - Собрание законодательства Российской Федерации, 2011, N 1, ст. 45).
