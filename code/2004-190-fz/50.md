# Статья 50. Негосударственная экспертиза проектной документации
1. Застройщик или заказчик либо осуществляющее на основании договора с застройщиком или заказчиком подготовку проектной документации лицо может направить проектную документацию на негосударственную экспертизу.
2. Негосударственная экспертиза проектной документации проводится на основании договора.
3. Негосударственная экспертиза проектной документации проводится аккредитованными организациями в порядке, установленном Правительством Российской Федерации.
