# Статья 74. Система проведения лесоустройства
Лесоустройство на территории лесного фонда Российской Федерации проводится государственными лесоустроительными организациями федерального органа управления лесным хозяйством. Лесоустройство выполняется по единой системе в порядке, устанавливаемом федеральным органом управления лесным хозяйством.
Ведение лесного хозяйства и лесопользования без проведения лесоустройства запрещается.
