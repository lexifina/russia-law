# Статья 121. Порядок пользования участками лесного фонда для нужд охотничьего хозяйства
Участки лесного фонда гражданам и юридическим лицам могут предоставляться в пользование для нужд охотничьего хозяйства в порядке, установленном настоящими Кодексом.
Порядок пользования участками лесного фонда для нужд охотничьего хозяйства устанавливается органами государственной власти субъектов Российской Федерации.
Участки лесного фонда для организации любительской и спортивной охоты общественным объединениям охотников передаются в безвозмездное пользование.
