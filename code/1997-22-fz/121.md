# Статья 121. Порядок пользования участками лесного фонда для нужд охотничьего хозяйства
Участки лесного фонда гражданам и юридическим лицам могут предоставляться в пользование для нужд охотничьего хозяйства в порядке, установленном настоящими Кодексом.
Порядок пользования участками лесного фонда для нужд охотничьего хозяйства устанавливается федеральным органом исполнительной власти, осуществляющим функции по выработке государственной политики и нормативно-правовому регулированию в области лесного хозяйства. (В редакции Федерального закона от 29.12.2004 г. N 199-ФЗ)
