# Статья 61. Порядок установления возраста рубок
Возраст рубок определяется исходя из значения и продуктивности лесов, выполняемых ими функций, а также биологических особенностей произрастающих древесных пород.
Обоснование возраста рубок проводится при лесоустройстве или по результатам научных исследований.
Установление возраста рубок осуществляется федеральным органом управления лесным хозяйством.
