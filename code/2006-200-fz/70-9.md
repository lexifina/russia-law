# Статья 70⁹. Лесоустроительная документация
1. Лесоустроительная документация составляется по результатам осуществления мероприятий по лесоустройству, предусмотренных статьей 70⁵ настоящего Кодекса, в электронной форме и включается в состав сведений государственного лесного реестра.
2. Лесоустроительная документация, в том числе составленная в отношении лесных участков, предоставленных по основаниям, предусмотренным настоящим Кодексом, утверждается органами государственной власти и органами местного самоуправления, уполномоченными в соответствии со статьями 81 - 84 настоящего Кодекса на осуществление мероприятий по лесоустройству, путем заверения усиленной квалифицированной электронной подписью уполномоченного должностного лица таких органов.
3. Срок действия лесоустроительной документации, составленной по результатам таксации лесов, составляет десять лет.
