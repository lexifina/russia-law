# Статья 14. Лесоперерабатывающая инфраструктура
1. Для переработки древесины и иных лесных ресурсов создается лесоперерабатывающая инфраструктура (объекты переработки заготовленной древесины, биоэнергетические объекты и другое).
2. Создание лесоперерабатывающей инфраструктуры запрещается в защитных лесах, а также в иных предусмотренных настоящим Кодексом, другими федеральными законами случаях.
