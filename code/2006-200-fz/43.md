# Статья 43. Использование лесов для выполнения работ по геологическому изучению недр, для разработки месторождений полезных ископаемых
1. Использование лесов для выполнения работ по геологическому изучению недр, для разработки месторождений полезных ископаемых осуществляется в соответствии со статьей 21 настоящего Кодекса.
2. Для выполнения работ по геологическому изучению недр, для разработки месторождений полезных ископаемых лесные участки, находящиеся в государственной или муниципальной собственности, предоставляются в аренду, за исключением случаев, предусмотренных частью 3 настоящей статьи. Для выполнения работ по геологическому изучению недр в отношении лесных участков может быть установлен сервитут (в ред. Федерального закона от 3 августа 2018 г. N 341-ФЗ - Собрание законодательства Российской Федерации, 2018, N 32, ст. 5134).
3. На основании разрешений органов государственной власти, органов местного самоуправления в пределах их полномочий, определенных в соответствии со статьями 81 - 84 настоящего Кодекса, допускается выполнение работ по геологическому изучению недр на землях лесного фонда без предоставления лесного участка, если выполнение таких работ не влечет за собой проведение рубок лесных насаждений, строительство объектов капитального строительства (в ред. Федерального закона от 14 июня 2011 г. N 137-ФЗ - Собрание законодательства Российской Федерации, 2011, N 25, ст. 3530).
3-1. В целях обеспечения безопасности граждан и создания необходимых условий для эксплуатации объектов, связанных с выполнением работ по геологическому изучению недр и разработкой месторождений полезных ископаемых, в том числе в охранных зонах указанных объектов, осуществляется использование лесов для проведения выборочных рубок и сплошных рубок деревьев, кустарников, лиан без предоставления лесных участков (часть 3-1 введена Федеральным законом от 22 июля 2008 г. N 143-ФЗ - Собрание законодательства Российской Федерации, 2008, N 30, ст. 3599; в ред. Федерального закона от 29 декабря 2010 г. N 442-ФЗ - Собрание законодательства Российской Федерации, 2011, N 1, ст. 54).
4. Порядок использования лесов для выполнения работ по геологическому изучению недр, для разработки месторождений полезных ископаемых устанавливается уполномоченным федеральным органом исполнительной власти.
