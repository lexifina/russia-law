# Статья 70¹³. Исчисление допустимого ежегодного объема изъятия древесины и изменения этого объема
1. Допустимый ежегодный объем изъятия древесины исчисляется по каждому лесничеству и (или) лесному участку отдельно для эксплуатационных и защитных лесов по преобладающим древесным породам.
2. Исчисление допустимого ежегодного объема изъятия древесины и изменения этого объема осуществляется для каждой из зон освоения лесов.
