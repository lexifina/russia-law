# Статья 88. Исполнение определения суда о применении мер предварительной защиты по административному иску
1. Определение суда о применении мер предварительной защиты по административному иску приводится в исполнение немедленно в порядке, установленном для исполнения судебных актов.
2. На лиц, виновных в неисполнении определения суда о применении мер предварительной защиты по административному иску, может быть наложен судебный штраф в порядке и размере, установленных статьями 122 и 123 настоящего Кодекса.
