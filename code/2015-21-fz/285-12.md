# Статья 285¹². Обжалование решения суда по административному делу, связанному с пребыванием несовершеннолетнего в центре временного содержания
Решение суда по административному делу, связанному с пребыванием несовершеннолетнего в центре временного содержания, может быть обжаловано лицами, участвующими в деле, в том числе несовершеннолетним, достигшим возраста четырнадцати лет, их представителями по общим правилам, установленным настоящим Кодексом.
Глава 31³. Производство по административным делам, связанным с пребыванием несовершеннолетнего в специальном учебно-воспитательном учреждении закрытого типа
(Дополнение главой - Федеральный закон от 21.11.2022 № 445-ФЗ)
