# Статья 104⁴. Судебный штраф
1. Судебный штраф есть денежное взыскание, назначаемое судом при освобождении лица от уголовной ответственности в случаях, предусмотренных статьей 76² настоящего Кодекса.
2. В случае неуплаты судебного штрафа в установленный судом срок судебный штраф отменяется и лицо привлекается к уголовной ответственности по соответствующей статье Особенной части настоящего Кодекса.
(Статья введена - Федеральный закон от 03.07.2016 № 323-ФЗ)
