# Статья 87. Особое пользование водными объектами
Для обеспечения нужд обороны, федеральных энергетических систем, федерального транспорта, а также для иных государственных и муниципальных нужд водные объекты, находящиеся в федеральной собственности, могут предоставляться в особое пользование по решению Правительства Российской Федерации.
(Часть вторая утратила силу - Федеральный закон от 22.08.2004 г. N 122-ФЗ)
В решении о предоставлении водных объектов в особое пользование указываются цель и основные условия использования водных объектов.
Порядок предоставления водных объектов в особое пользование устанавливается Правительством Российской Федерации.
