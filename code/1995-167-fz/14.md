# Статья 14. Внутренние морские воды
К внутренним морским водам относятся морские воды, расположенные в сторону берега от исходных линий, принятых для отсчета ширины территориального моря Российской Федерации.
Порядок использования и охраны внутренних морских вод устанавливается настоящим Кодексом и иными федеральными законами.
