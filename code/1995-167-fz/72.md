# Статья 72. Органы исполнительной власти субъектов Российской Федерации в области использования и охраны водных объектов
Государственное управление в области использования и охраны водных объектов на территории субъектов Российской Федерации осуществляют органы исполнительной власти республик, краев, областей, городов федерального значения, автономной области, автономных округов.
