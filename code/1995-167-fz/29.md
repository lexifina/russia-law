# Статья 29. Водопользователь, использующий водные объекты для обеспечения нужд водопотребителей
Водопользователь, использующий водные объекты для обеспечения нужд водопотребителей, обязан осуществлять соответствующую деятельность в соответствии с лицензией на водопользование и договором пользования водным объектом.
