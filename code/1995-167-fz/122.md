# Статья 122. Платность водопользования
Пользование водными объектами является платным. Порядок установления, зачисления, взимания платы, связанной с пользованием водными объектами, и предельные размеры такой платы определяются законодательством Российской Федерации. (В редакции Федерального закона от 22.08.2004 г. N 122-ФЗ)
