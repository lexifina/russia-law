# Статья 68. Полномочия органов местного самоуправления в области использования и охраны водных объектов
Органам местного самоуправления могут передаваться отдельные государственные полномочия в области использования и охраны водных объектов в соответствии с законодательством Российской Федерации и необходимые для реализации указанных полномочий материальные и финансовые средства. Реализация переданных полномочий подконтрольна государству.
