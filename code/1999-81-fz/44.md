# Статья 44. Повторная регистрация судна
В случае, если в результате происшествия или по любой другой причине судно перестает соответствовать сведениям, ранее внесенным в Государственный судовой реестр, Российский международный реестр судов или судовую книгу, может быть осуществлена повторная регистрация этого судна после его освидетельствования.
(Статья в редакции Федерального закона от 14.06.2011 г. N 141-ФЗ)
