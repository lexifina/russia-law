# Статья 78. Распоряжения капитана морского порта
Распоряжения капитана морского порта по относящимся к его полномочиям вопросам обязательны для всех находящихся в порту судов, организаций и граждан (в ред. Федерального закона от 29 декабря 2017 г. N 460-ФЗ - Собрание законодательства Российской Федерации, 2018, N 1, ст. 44).
