# Статья 16. Возникновение права плавания под Государственным флагом Российской Федерации
Судно приобретает право плавания под Государственным флагом Российской Федерации с даты его государственной регистрации (в ред. Федерального закона от 29 декабря 2017 г. N 460-ФЗ - Собрание законодательства Российской Федерации, 2018, N 1, ст. 44).
