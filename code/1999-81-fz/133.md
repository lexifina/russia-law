# Статья 133. Плата за досрочное окончание погрузки груза
Размер платы, причитающейся фрахтователю за окончание погрузки груза до истечения сталийного времени (диспач), определяется соглашением сторон. При отсутствии соглашения сторон диспач исчисляется в размере одной второй демереджа. (В редакции Федерального закона от 14.06.2011 № 141-ФЗ)
