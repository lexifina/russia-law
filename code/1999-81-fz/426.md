# Статья 426. Ограничение ответственности по морским требованиям
К ограничению ответственности по морским требованиям применяется закон государства, в суде которого рассматривается морское требование, подпадающее под ограничение ответственности (в ред. Федерального закона от 14 июня 2011 г. N 141-ФЗ - Собрание законодательства Российской Федерации, 2011, N 25, ст. 3534).
