# Статья 51. Ответственность за нарушение правил государственной регистрации судов
(наименование в ред. Федерального закона от 23 апреля 2012 г. N 36-ФЗ - Собрание законодательства Российской Федерации, 2012, N 18, ст. 2128)
Лицо, уклоняющееся от обязательной государственной регистрации судна, зарегистрировавшее его в одном из реестров судов с нарушением установленного порядка или нарушившее обязанность информировать об изменении сведений, вносимых в реестры судов, несет административную ответственность в соответствии с законодательством Российской Федерации (в ред. Федерального закона от 23 апреля 2012 г. N 36-ФЗ - Собрание законодательства Российской Федерации, 2012, N 18, ст. 2128).
