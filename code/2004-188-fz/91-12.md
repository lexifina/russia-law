# Статья 91¹². Выселение граждан из жилого помещения, предоставленного по договору найма жилого помещения жилищного фонда социального использования
При расторжении договора найма жилого помещения жилищного фонда социального использования наниматель и другие граждане, проживающие в жилом помещении, подлежат выселению из жилого помещения на основании решения суда без предоставления другого жилого помещения (статья введена - Федеральный закон от 21 июля 2014 г. № 217-ФЗ).
