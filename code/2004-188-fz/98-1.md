# Статья 98-1. Назначение жилых помещений для детей-сирот и детей, оставшихся без попечения родителей, лиц из числа детей-сирот и детей, оставшихся без попечения родителей
Жилые помещения для детей-сирот и детей, оставшихся без попечения родителей, лиц из числа детей-сирот и детей, оставшихся без попечения родителей, предназначены для проживания детей-сирот и детей, оставшихся без попечения родителей, лиц из числа детей-сирот и детей, оставшихся без попечения родителей, в соответствии с законодательством Российской Федерации и законодательством субъектов Российской Федерации (статья 98-1 введена Федеральным законом от 29 февраля 2012 г. N 15-ФЗ - Собрание законодательства Российской Федерации, 2012, N 10, ст. 1163).
