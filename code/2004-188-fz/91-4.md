# Статья 91⁴. Пользование жилым помещением по договору найма жилого помещения жилищного фонда социального использования
Пользование жилым помещением по договору найма жилого помещения жилищного фонда социального использования осуществляется в соответствии с настоящим Кодексом и данным договором. (Статья введена - Федеральный закон от 21.07.2014 № 217-ФЗ)
