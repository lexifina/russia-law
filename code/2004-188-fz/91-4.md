# Статья 91-4. Пользование жилым помещением по договору найма жилого помещения жилищного фонда социального использования
Пользование жилым помещением по договору найма жилого помещения жилищного фонда социального использования осуществляется в соответствии с настоящим Кодексом и данным договором (статья 91-4 введена Федеральным законом от 21 июля 2014 г. N 217-ФЗ - Собрание законодательства Российской Федерации, 2014, N 30, ст. 4218).
