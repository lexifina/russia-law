# Статья 91⁴. Пользование жилым помещением по договору найма жилого помещения жилищного фонда социального использования
Пользование жилым помещением по договору найма жилого помещения жилищного фонда социального использования осуществляется в соответствии с настоящим Кодексом и данным договором (статья введена Федеральным законом от 21 июля 2014 г. № 217-ФЗ).
