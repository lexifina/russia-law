# Статья 96. Назначение жилых помещений в домах системы социального обслуживания граждан
Жилые помещения в домах системы социального обслуживания граждан предназначаются для проживания граждан, являющихся получателями социальных услуг и признанных нуждающимися в социальном обслуживании (в ред. Федерального закона от 28 ноября 2015 г. № 358-ФЗ).
