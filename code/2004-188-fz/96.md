# Статья 96. Назначение жилых помещений в домах системы социального обслуживания граждан
Жилые помещения в домах системы социального обслуживания граждан предназначаются для проживания граждан, являющихся получателями социальных услуг и признанных нуждающимися в социальном обслуживании (в ред. Федерального закона от 28 ноября 2015 г. N 358-ФЗ - Собрание законодательства Российской Федерации, 2015, N 48, ст. 6724).
