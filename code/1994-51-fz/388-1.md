# Статья 388¹. Уступка будущего требования
1. Требование по обязательству, которое возникнет в будущем (будущее требование), в том числе требование по обязательству из договора, который будет заключен в будущем, должно быть определено в соглашении об уступке способом, позволяющим идентифицировать это требование на момент его возникновения или перехода к цессионарию. (В редакции Федерального закона от 08.03.2015 № 42-ФЗ)
2. Если иное не установлено законом, будущее требование переходит к цессионарию с момента его возникновения. Соглашением сторон может быть предусмотрено, что будущее требование переходит позднее.
