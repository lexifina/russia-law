# Статья 358¹¹. Возникновение залога прав по договору банковского счета
Залог на основании договора залога прав по договору банковского счета возникает с момента уведомления банка о залоге прав и предоставления ему копии договора залога. В случае, если залогодержателем является банк, заключивший с клиентом (залогодателем) договор залогового счета, залог возникает с момента заключения договора залога прав по банковскому счету. (Статья введена - Федеральный закон от 21.12.2013 № 367-ФЗ)
