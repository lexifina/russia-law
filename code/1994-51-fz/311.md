# Статья 311. Исполнение обязательства по частям
Кредитор вправе не принимать исполнения обязательства по частям, если иное не предусмотрено законом, иными правовыми актами, условиями обязательства и не вытекает из обычаев или существа обязательства. (В редакции Федерального закона от 08.03.2015 № 42-ФЗ)
