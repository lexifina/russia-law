# Статья 358¹³. Изменение и прекращение договора залога прав по договору банковского счета
Без согласия залогодержателя стороны договора банковского счета, права по которому заложены, не вправе вносить в него изменения, а также совершать действия, влекущие прекращение такого договора. (Статья введена - Федеральный закон от 21.12.2013 № 367-ФЗ)
