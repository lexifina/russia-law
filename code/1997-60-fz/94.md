# Статья 94. Прекращение поиска потерпевшего бедствие воздушного судна, его пассажиров и экипажа
1. В случае, если все принятые для поиска потерпевшего бедствие воздушного судна, его пассажиров и экипажа меры не дали результатов, решение о прекращении поиска этого воздушного судна принимается уполномоченным органом, осуществившим государственную регистрацию или государственный учет этого воздушного судна. (В редакции Федерального закона от 22.08.2004 г. N 122-ФЗ)
2. Решение о прекращении поиска потерпевшего бедствие воздушного судна иностранного государства принимается уполномоченным органом в области использования воздушного пространства. (В редакции Федерального закона от 04.12.2007 г. N 332-ФЗ)
3. Потерпевшее бедствие воздушное судно, поиск которого официально прекращен, считается пропавшим без вести.
