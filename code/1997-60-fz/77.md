# Статья 77. Использование средств связи общего назначения
Порядок использования средств связи общего назначения для обеспечения полетов воздушных судов устанавливается специально уполномоченным органом в области связи по согласованию со специально уполномоченным органом в области гражданской авиации, специально уполномоченным органом в области обороны или специально уполномоченным органом в области оборонной промышленности.
