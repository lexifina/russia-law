# Статья 77. Использование средств связи общего назначения
Порядок использования средств связи общего назначения для обеспечения полетов воздушных судов устанавливается уполномоченным органом в области связи по согласованию с уполномоченным органом в области гражданской авиации, уполномоченным органом в области обороны или уполномоченным органом в области оборонной промышленности. (В редакции Федерального закона от 22.08.2004 г. N 122-ФЗ)
