# Статья 43. Предоставление земельного участка или поверхностного водного объекта
Земельный участок, предназначенный для размещения аэродрома, аэропорта или объекта единой системы организации воздушного движения, поверхностный водный объект, предназначенный для размещения аэродрома, предоставляются в соответствии с законодательством Российской Федерации. (Статья в редакции Федерального закона от 26.06.2007 № 118-ФЗ)
