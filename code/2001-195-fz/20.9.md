# Статья 20.9. Установка на гражданском или служебном оружии приспособления для бесшумной стрельбы либо продажа приспособления для бесшумной стрельбы
Установка на гражданском или служебном оружии приспособления для бесшумной стрельбы либо продажа приспособления для бесшумной стрельбы -
влечет наложение административного штрафа в размере от двух тысяч до двух тысяч пятисот рублей с конфискацией приспособления для бесшумной стрельбы.
(Статья в редакции Федерального закона от 26.07.2026 № 249-ФЗ)
