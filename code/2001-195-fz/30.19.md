# Статья 30.19. Вступление в законную силу постановления, принятого по результатам рассмотрения жалобы, протеста на вступившие в законную силу постановление по делу об административном правонарушении, решения по результатам рассмотрения жалоб, протестов
(наименование в ред. Федерального закона от 4 июня 2014 г. N 143-ФЗ - Собрание законодательства Российской Федерации, 2014, N 23, ст. 2928)
Постановление, принятое по результатам рассмотрения жалобы, протеста на вступившие в законную силу постановление по делу об административном правонарушении, решения по результатам рассмотрения жалоб, протестов, вступает в законную силу со дня его принятия (статья 30.19 введена Федеральным законом от 3 декабря 2008 г. N 240-ФЗ - Собрание законодательства Российской Федерации, 2008, N 49, ст. 5738; в ред. Федерального закона от 4 июня 2014 г. N 143-ФЗ - Собрание законодательства Российской Федерации, 2014, N 23, ст. 2928).
