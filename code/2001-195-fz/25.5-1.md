# Статья 25.5¹. Уполномоченный при Президенте Российской Федерации по защите прав предпринимателей
Уполномоченный при Президенте Российской Федерации по защите прав предпринимателей по ходатайству лица, в отношении которого ведется производство по делу об административном правонарушении в области предпринимательской деятельности, может быть допущен к участию в деле в качестве защитника (статья введена - Федеральный закон от 2 ноября 2013 г. № 294-ФЗ).
