# Статья 25.5¹. Уполномоченный при Президенте Российской Федерации по защите прав предпринимателей
(Наименование с 25.07.2022 в редакции Федерального закона от 14.07.2022 № 290-ФЗ)
Уполномоченный при Президенте Российской Федерации по защите прав предпринимателей по ходатайству лица, в отношении которого ведется производство по делу об административном правонарушении в области предпринимательской деятельности, может быть допущен к участию в деле в качестве защитника.
(Статья 25.5¹ с 25.07.2022 в редакции Федерального закона от 14.07.2022 № 290-ФЗ)
(Дополнение статьей - Федеральный закон от 02.11.2013 № 294-ФЗ)
