# Статья 25.5-1. Уполномоченный при Президенте Российской Федерации по защите прав предпринимателей
Уполномоченный при Президенте Российской Федерации по защите прав предпринимателей по ходатайству лица, в отношении которого ведется производство по делу об административном правонарушении в области предпринимательской деятельности, может быть допущен к участию в деле в качестве защитника (статья 25.5-1 введена Федеральным законом от 2 ноября 2013 г. N 294-ФЗ - Собрание законодательства Российской Федерации, 2013, N 44, ст. 5633).
