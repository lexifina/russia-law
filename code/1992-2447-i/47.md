# Статья 47. Порядок проведения экспертизы
Экспертиза проводится экспертами соответствующих учреждений либо иными специалистами, назначенными арбитражным судом. В качестве эксперта может быть вызвано любое лицо, обладающее необходимыми познаниями для дачи заключения. При назначении эксперта арбитражный суд учитывает мнение лиц, участвующих в деле.
Экспертиза проводится в арбитражном суде или вне арбитражного суда, если это необходимо по характеру исследования либо в силу затруднительности доставить предмет исследования в арбитражный суд.
При назначении нескольких экспертов они вправе совещаться между собой. Если эксперты придут к общему выводу, они все подписывают одно заключение. В случае несогласия с другими экспертами эксперт дает самостоятельное отдельное заключение.
