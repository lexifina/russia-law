# Статья 93. Замена одного вида обеспечения иска другим
Допускается замена одного вида обеспечения иска другим.
Вопрос о замене одного вида обеспечения иска другим разрешается в порядке, установленном частью первой статьи 94 настоящего Кодекса.
При обеспечении иска о взыскании денежных средств ответчик вправе вместо принятия установленных мер обеспечения иска внести на депозитный счет арбитражного суда истребуемую истцом сумму.
