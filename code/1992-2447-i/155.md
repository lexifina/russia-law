# Статья 155. Восстановление пропущенного срока для предъявления приказа к исполнению
При пропуске срока предъявления приказа к исполнению по причинам, признанным арбитражным судом уважительными, пропущенный срок может быть восстановлен, если иное не установлено законом.
Заявление о восстановлении пропущенного срока подается в арбитражный суд, принявший решение. Заявление рассматривается в заседании арбитражного суда.
На определение арбитражного суда по вопросу о восстановлении срока может быть подана кассационная жалоба или принесен протест.
