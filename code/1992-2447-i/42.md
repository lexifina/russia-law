# Статья 42. Основания освобождения от доказывания
Обстоятельства, признанные арбитражным судом общеизвестными, не нуждаются в доказывании.
Факты, установленные вступившим в законную силу решением арбитражного суда при разрешении одного спора, не доказываются вновь при разрешении других споров, в которых участвуют те же организации и граждане-предприниматели.
Вступивший в законную силу приговор суда по уголовному делу обязателен для арбитражного суда, разрешающего спор, по вопросам, имели ли место определенные действия и кем они совершены.
Вступившее в законную силу решение суда по гражданскому делу обязательно для арбитражного суда, разрешающего спор, по вопросам о фактах, установленных судом и имеющих значение для дела.
