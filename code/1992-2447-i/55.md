# Статья 55. Порядок обеспечения доказательств
Обеспечение доказательств производится судьей по правилам, установленным настоящим Кодексом.
Лица, участвующие в деле, извещаются о времени и месте рассмотрения заявления об обеспечении доказательств, однако их неявка не является препятствием к рассмотрению заявления.
