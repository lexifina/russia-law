# Статья 88. Направление определений о принятии дела к производству
Определения о принятии дела к производству направляются извещаемому или вызываемому лицу заказным письмом по адресу, указанному стороной или другим лицом, участвующим в деле. Если по сообщенному арбитражному суду адресу гражданин-предприниматель фактически не проживает, определение может быть направлено по месту его работы.
