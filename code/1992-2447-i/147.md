# Статья 147. Пересмотр по вновь открывшимся обстоятельствам постановлений и определений
Пересмотр по вновь открывшимся обстоятельствам постановлений и определений арбитражного суда, которые могут быть пересмотрены в кассационном и надзорном порядке, производится по правилам, установленным для пересмотра по вновь открывшимся обстоятельствам решений арбитражных судов.
Глава ХVI. ИСПОЛНЕНИЕ РЕШЕНИЙ
