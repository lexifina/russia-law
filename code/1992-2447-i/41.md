# Статья 41. Относимость и допустимость доказательств
Арбитражный суд принимает только те доказательства, которые имеют отношение к делу.
Обстоятельства дела, которые согласно законодательству должны быть подтверждены определенными средствами доказывания, не могут быть подтверждены никакими другими средствами доказывания.
