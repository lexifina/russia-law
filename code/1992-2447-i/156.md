# Статья 156. Порядок обращения взыскания на имущество
При отсутствии у организации, гражданина-предпринимателя денежных средств, достаточных для исполнения решения арбитражного суда, взыскание может быть обращено на любое принадлежащее должнику имущество.
В случаях, предусмотренных законодательными актами Российской Федерации, взыскание может быть обращено на имущество другой организации, гражданина-предпринимателя.
Денежные средства и имущество граждан-предпринимателей, на которые не может быть обращено взыскание, определяются законодательными актами Российской Федерации.
