# Статья 46. Назначение экспертизы арбитражным судом
Для разъяснения возникающих при рассмотрении дела вопросов, требующих специальных познаний в области науки, искусства, техники или ремесла, суд назначает экспертизу.
Каждое лицо, участвующее в деле, вправе представить арбитражному суду вопросы, которые должны быть разъяснены экспертизой. Окончательно круг вопросов, по которым требуется заключение экспертизы, определяется арбитражным судом. Отклонение предложенных вопросов арбитражный суд обязан мотивировать.
