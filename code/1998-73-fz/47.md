# Статья 47. Зоны специального назначения
1. Зоны специального назначения выделяются для размещения кладбищ, крематориев, скотомогильников, свалок бытовых отходов и иных объектов, использование которых несовместимо с использованием других видов территориальных зон городских и сельских поселений.
2. Порядок использования территорий зон специального назначения устанавливается правилами застройки с учетом требований государственных градостроительных нормативов и правил, специальных нормативов.
