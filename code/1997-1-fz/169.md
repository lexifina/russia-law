# Статья 169. Порядок применения мер поощрения и взыскания
Права командиров дисциплинарных воинских частей по применению мер поощрения и взыскания, порядок применения и учета указанных мер определяются федеральным органом исполнительной власти, осуществляющим функции по выработке и реализации государственной политики, нормативно-правовому регулированию в области обороны, в соответствии с требованиями воинских уставов (в ред. Федерального закона от 8 ноября 2008 г. N 194-ФЗ - Собрание законодательства Российской Федерации, 2008, N 45, ст. 5140).
