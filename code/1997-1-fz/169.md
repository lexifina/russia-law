# Статья 169. Порядок применения мер поощрения и взыскания
Права командиров дисциплинарных воинских частей по применению мер поощрения и взыскания, порядок применения и учета указанных мер определяются федеральным органом исполнительной власти, осуществляющим функции по выработке и реализации государственной политики, нормативно-правовому регулированию в области обороны, в соответствии с требованиями воинских уставов. (В редакции Федерального закона от 08.11.2008 № 194-ФЗ)
