# Статья 77. Оставление осужденных к лишению свободы в следственном изоляторе или тюрьме для выполнения работ по хозяйственному обслуживанию
(наименование в ред. Федерального закона от 16 марта 1999 г. N 49-ФЗ - Собрание законодательства Российской Федерации, 1999, N 12, ст. 1406)
1. В исключительных случаях лица, осужденные к лишению свободы, ранее не отбывавшие лишение свободы, которым отбывание наказания назначено в исправительной колонии общего режима, могут быть с их согласия оставлены в следственном изоляторе или тюрьме для выполнения работ по хозяйственному обслуживанию (в ред. Федерального закона от 3 апреля 2006 г. N 46-ФЗ - Собрание законодательства Российской Федерации, 2006, N 15, ст. 1575).
2. Осужденные оставляются для выполнения работ по хозяйственному обслуживанию решением начальника следственного изолятора или тюрьмы при наличии согласия осужденного в письменной форме.
3. Осужденные, оставленные в следственном изоляторе или тюрьме для выполнения работ по хозяйственному обслуживанию, содержатся в незапираемых общих камерах отдельно от иных лиц на условиях, предусмотренных настоящим Кодексом для исправительных колоний общего режима, и пользуются правом ежедневной прогулки продолжительностью два часа.
(Части четвертая - седьмая исключены Федеральным законом от 16 марта 1999 г. N 49-ФЗ - Собрание законодательства Российской Федерации, 1999, N 12, ст. 1406)
