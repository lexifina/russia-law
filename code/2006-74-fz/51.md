# Статья 51. Использование водных объектов для целей охоты
Использование водных объектов для целей охоты осуществляется в соответствии с водным законодательством и законодательством в области охоты и сохранения охотничьих ресурсов (статья 51 в ред. Федерального закона от 28 декабря 2010 г. N 420-ФЗ - Собрание законодательства Российской Федерации, 2011, N 1, ст. 32).
