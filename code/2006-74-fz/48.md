# Статья 48. Использование водных объектов для сплава леса
1. Водопользователи, осуществляющие сплав леса, обязаны регулярно проводить очистку водных объектов от затонувшей древесины.
2. Сплав леса без судовой тяги на водных объектах, используемых для судоходства, и молевой сплав леса на водных объектах запрещаются.
