# Статья 51². Использование водных объектов для целей эксплуатации мостов, подводных и подземных переходов, трубопроводов, подводных линий связи, других линейных объектов
Использование водных объектов для целей эксплуатации мостов, подводных и подземных переходов, трубопроводов, подводных линий связи, других линейных объектов осуществляется в соответствии с законодательством Российской Федерации без предоставления водных объектов в пользование. (Статья введена - Федеральный закон от 26.07.2017 № 208-ФЗ)
