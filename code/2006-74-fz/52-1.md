# Статья 52¹. Использование водных объектов для проведения строительных, дноуглубительных, взрывных, буровых и других работ
Использование водных объектов для проведения строительных, дноуглубительных, взрывных, буровых и других работ, связанных с изменением дна и берегов водных объектов, осуществляется в соответствии с настоящим Кодексом и другими федеральными законами. (Статья введена - Федеральный закон от 07.05.2013 № 87-ФЗ)
