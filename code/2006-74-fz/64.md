# Статья 64. Зоны, округа санитарной охраны водных объектов, водные ресурсы которых являются природными лечебными ресурсами
В целях охраны водных объектов, обладающих природными лечебными ресурсами, устанавливаются округа санитарной (горно-санитарной) охраны природных лечебных ресурсов в соответствии с законодательством Российской Федерации о природных лечебных ресурсах, лечебно-оздоровительных местностях и курортах. (В редакции Федерального закона от 04.08.2023 № 469-ФЗ)
