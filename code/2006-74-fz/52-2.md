# Статья 52². Использование водных объектов для строительства, реконструкции и эксплуатации гидротехнических сооружений
Использование водных объектов для строительства, реконструкции и эксплуатации гидротехнических сооружений осуществляется в соответствии с настоящим Кодексом и другими федеральными законами. (Статья введена - Федеральный закон от 16.12.2019 № 431-ФЗ)
