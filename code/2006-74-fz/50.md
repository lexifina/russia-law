# Статья 50. Использование водных объектов для рекреационных целей
1. Использование водных объектов для рекреационных целей (отдыха, туризма, спорта) осуществляется с учетом правил использования водных объектов, устанавливаемых органами местного самоуправления в соответствии со статьей 6 настоящего Кодекса.
2. Проектирование, строительство, реконструкция, ввод в эксплуатацию и эксплуатация зданий, строений, сооружений для рекреационных целей, в том числе для обустройства пляжей, осуществляются в соответствии с водным законодательством и законодательством о градостроительной деятельности. (В редакции Федерального закона от 14.07.2008 г. N 118-ФЗ)
