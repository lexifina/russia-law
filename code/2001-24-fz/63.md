# Статья 63. Права и обязанности арендодателя при аренде судна без экипажа
1. Арендодатель обязан передать арендатору документы, предусмотренные законодательством в области внутреннего водного транспорта Российской Федерации, для эксплуатации арендуемого судна.
2. В случае, если арендодатель не является собственником судна, он обязан извещать собственника судна обо всех заключенных в отношении данного судна договорах аренды (в ред. Федерального закона от 28 июля 2012 г. N 131-ФЗ - Собрание законодательства Российской Федерации, 2012, N 31, ст. 4320).
3. Устранение скрытых недостатков судна является обязанностью арендодателя.
4. Договор аренды судна без экипажа вступает в силу после регистрации этого договора органом государственной регистрации судна (пункт 4 введен Федеральным законом от 28 июля 2012 г. N 131-ФЗ - Собрание законодательства Российской Федерации, 2012, N 31, ст. 4320).
